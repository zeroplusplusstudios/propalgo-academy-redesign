# PropAlgo Academy — homepage redesign concept

A single-page redesign of the propalgoacademy.com homepage. All copy, links and disclaimers are unchanged from the live site; only the design, layout and interactions are new.

- Navy + mint theme with a light/dark toggle
- Animated, clearly labelled simulated candlestick chart
- Mobile sticky counselling CTA and WhatsApp button
- Respects `prefers-reduced-motion`; marked `noindex` (concept preview)

Images are loaded from propalgoacademy.com. Open `index.html` directly or view via GitHub Pages.
